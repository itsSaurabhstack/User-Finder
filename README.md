
# User Finder 🔍

A simple user search application built using HTML, CSS and JavaScript.



## ✨ Features

- Search users by name
- Display user information
- Show a message when no matching user is found
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
